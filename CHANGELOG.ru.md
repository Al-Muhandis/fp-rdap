# Changelog

[English](CHANGELOG.md) | Русский

Журнал релизов fp-rdap. Версия релиза — четыре компонента
`Major.Minor.Release.Build`, как её показывает OPM (Lazarus Online Package
Manager); тег релиза — `v<версия>`. Запись добавляется на каждый релиз;
изменения наблюдаемого поведения в процессе разработки фиксируются в README,
раздел «Изменения».

## Unreleased

Новое: консольная утилита `rdapcli`. Версия пакета и OPM-артефакты здесь
сознательно не тронуты — релизные шаги (версия, тег, перегенерация манифеста)
выполняются отдельно.

### Добавлено

- `cli/rdapcli.lpi` — консольная утилита в духе whois, витрина библиотеки:
  автодетект типа запроса (валидный IPv4/IPv6 → `ip`, `AS` + цифры →
  `autnum`, остальное → `domain`; опция `--type=` для entity-хендлов),
  `--raw` — тело ответа в stdout как есть, `--bootstrap-dir=ПАПКА` с фолбэком
  на `https://rdap.org/`, SOCKS5-опции `--proxy=host:port` / `--proxy-user=` /
  `--proxy-pass=`, справка `-h`/`--help` на английском. Коды выхода:
  0 — успех, 1 — не найдено (HTTP 404), 2 — rate limit (HTTP 429, с
  `Retry-After`), 3 — всё остальное. Результаты в stdout, уведомления и
  ошибки — в stderr. На Windows UTF-8 аргументы разбираются из широкой
  (UTF-16) командной строки — RTL `ParamStr` идёт через системную
  ANSI-кодировку и портит не-ASCII запросы (например, IDN-домены) на
  системах, где системная кодировка их не представима.
- Тип `TRDAPQueryType` и чистый хелпер `DetectQueryType` (экспортированы по
  конвенции «хелперы для тестов»): автодетект типа запроса на
  экспортированных парсерах IP — тот же синтаксис, который принимает
  `QueryIP`.
- Чистый хелпер `AutNumToAsplain`: сворачивает необязательный
  регистронезависимый префикс `AS` с цифрами в asplain-ключ, который RFC 9082
  требует в autnum-пути; всё остальное проходит без изменений.

### Изменено

- **Изменение поведения:** `QueryAutNum` нормализует ключ запроса к
  asplain-форме из RFC 9082 §3.1.2 (через `AutNumToAsplain` — так же, как
  `QueryDomain` конвертирует U-label в A-label): `QueryAutNum('AS15169')`
  запрашивает `autnum/15169`, раньше — `autnum/AS15169`, форму, на которую
  редиректоры вроде rdap.org отвечают 404. Утилита rdapcli соответственно
  убрала собственное сворачивание. Тестов: 83 (три новых, один обновлён).

## 1.1.0.0 — 2026-11-19

SOCKS5-прокси в транспорте (этап 6 дорожной карты). Первый релиз, доступный
установкой из Lazarus Online Package Manager (OPM).

### Добавлено

- `ProxyHost`/`ProxyPort`/`ProxyUser`/`ProxyPass`: при непустом `ProxyHost`
  запросы идут через SOCKS5-прокси (no-auth при пустом `ProxyUser`, user/pass
  при заданном); при пустом поведение не изменилось ни в чём. Транспорт
  прокси-режима — Synapse `THTTPSend` (новая зависимость `rdap_rt.lpk` —
  `laz_synapse`), TLS поверх туннеля — через `ssl_openssl`-плагин;
  `ConnectTimeout`/`IOTimeout` применяются и в прокси-режиме.
- Редиректы в прокси-режиме — ручной цикл до 5 переходов, только абсолютные
  `Location` (относительный — `ERDAPError`). `MaxResponseSize` в прокси-режиме
  применяется после полной загрузки тела — расхождение с прямой дорогой
  задокументировано в README («Ограничения»).
- Демо: CLI-параметры `--proxy=host:port`, `--proxy-user=`, `--proxy-pass=`.
- Тесты: loopback SOCKS5-стаб (`TThread` + слушающий сокет, без сети и DNS) —
  8 новых тестов, всего 80.

## 1.0.0.0 — 2026-11-14

Первый публичный релиз: RDAP-клиент для Free Pascal / Lazarus.

### Добавлено

- Запросы `domain`, `ip`, `autnum`, `entity` (RFC 9082/9083).
- Роутинг через bootstrap-файлы IANA (RFC 8524/9224/9225): загрузка с диска
  или из строки, longest-prefix для IP, multi-label TLD для доменов;
  перезагрузка отказоустойчива (parse-then-swap), записи `services`
  валидируются при выборке.
- IDNA: U-label домены конвертируются в A-label — punycode (RFC 3492) плюс
  прагматичное IDNA-маппирование fp-idn (приведение регистра ASCII/кириллицы/
  греческого, разделители label, отклонение недопустимых имён с `ERDAPError`)
  через пакет `fpidn_rt` ≥ 1.1
  ([fp-idn](https://github.com/al-muhandis/fp-idn)).
- Статусы результата `rqsOK`/`rqsNotFound`/`rqsRateLimited`/`rqsError`;
  разбор RFC 9083 error-объекта и заголовка `Retry-After` (секунды и
  HTTP-date).
- `MaxResponseSize` — лимит размера ответа (по умолчанию 10 МБ) с обрывом
  скачивания; таймауты соединения/IO, User-Agent, редиректы.
- `TRDAPClientMock` для тестов без сети: тело/код/заголовки ответа, история
  URL.
- Все строки библиотеки — UTF-8 по контракту; разбор JSON не зависит от
  кодипейджа процесса.

### Требования

FPC 3.2+, FCL (fpjson, fphttpclient), пакет `fpidn_rt`, OpenSSL-библиотеки
в PATH для HTTPS.
